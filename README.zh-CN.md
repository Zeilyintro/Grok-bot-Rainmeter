# Grok bot-Rainmeter

[English](README.md) | **简体中文**

更有情绪，也更有陪伴感。这个 Rainmeter 桌面 bot 会用眼神和表情回应你的靠近，在互动中慢慢形成性格，也会随着音乐摇摆。

**5.4 · 171 个样式 · 10 种身体 · 黑白主题**

5.4 更新：优化了内存占用。

## 主要特点

- **情绪互动**：靠近时逐渐展开笑眼，突然冲近可能受惊，反复快速穿过会不耐烦甚至生气，持续绕圈或大幅来回会晕。情绪随着互动叠加，再慢慢缓和；烦躁时会冒出怒气标记，惹急了还有乱线气泡。
- **性格与亲密度**：自然成长、黏人、高冷、胆小四档。同样的互动，会有不同的回应；自然成长时，胆量、黏人度、耐心和活跃度会缓慢变化，亲密度也会积累。
- **音乐律动**：跟随默认系统输出的音乐，左右摇摆、轻轻跳动，身旁还会飘起音符；新增墨镜和更丰富的跳舞表情，笑眼与墨镜自然交接；不耐烦时会暂停，缓和后再继续。
- **自己的小节奏**：鼠标闲置后会慢慢犯困，进入小睡或深睡，睡着时轻轻呼吸、冒出 Z 字。持续打扰或音乐能叫醒它；长睡时，鼠标持续活动约一分钟也会唤醒。被吵醒还可能有点起床气。不会真的移动窗口。
- **更多形态**：星星、花朵加入原有身体，共 171 个样式，支持 ^^ 笑眼、蚊香眼、平滑变形及黑白主题。

## 安装与升级

需要 Windows 10+、Rainmeter 4.5.46.3894+。

从 [5.4 发行页](https://github.com/Zeilyintro/Grok-bot-Rainmeter/releases/tag/v5.4) 下载 **Zeily-bot_5.4.rmskin**，双击安装，然后加载 `Bloub/Bloub.ini`。安装包包含 Settings.inc 和 32/64 位 MousePos 插件；音乐使用 Rainmeter 内置 AudioLevel，无需额外音乐插件。

升级前请备份 `Bloub.ini` 和 `@Resources/Settings.inc`。安装后保留自己的尺寸、速度、开关及成长数据；不要先删除旧皮肤。从 4.2 升级请使用完整安装包，不能只替换 Lua。

## 使用

- **右键菜单**：跟随系统、白色主题、眼睛跟随鼠标、鼠标互动、随音乐律动、互动强度、性格，以及重置性格成长与亲密度。
- **主题**：手动选色前先关闭系统主题跟随。
- **互动**：眼睛跟随与鼠标互动是独立开关。互动强度可选自动、完整、克制；左键不再切换样式。
- **尺寸与速度**：修改 `Bloub.ini` 中的 `Size`、`Speed` 后刷新。编辑 INI 时保留原来的 UTF-16 编码。
